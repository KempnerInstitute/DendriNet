Bases: BaseNetwork

A neural network model that implements excitatory and inhibitory pathways. This is a placeholder implementation based on common patterns.

The main network class implementing multi-layer excitatory-inhibitory networks with dendritic computation.

Example usage:

from dendritic_modeling.networks import ExcitationInhibitionNetwork

# Create a 3-layer E/I network
network = ExcitationInhibitionNetwork(
    input_dim=784,
    n_layers=3,
    n_excitatory=[200, 100, 10],
    n_inhibitory=[50, 25, 0],
    n_branches=[20, 15, 10],
    connectivity="sparse",
    sparsity=0.2,
    epsilon=1e-6
)

# Forward pass
output = network(input_tensor)

Converting CNNs

dendritic_modeling.networks.convert.cnn_to_dendrite.conv2d_to_dendrite(conv: Conv2d, *, baseline_inhib: float = 0.1, eps: float = 1e-06, copy_bias: bool = False) → DendriteConv2d[source]

Return a DendriteConv2d whose E/I weights equal the push–pull decomposition of conv.

Parameters:

  • conv – Trained or un-trained Conv2d to mimic.

  • baseline_inhib – Constant added to inhibitory weights to keep denominator positive.

  • eps – Numerical epsilon added before log.

  • copy_bias – If True and conv.bias is not None, the bias term is copied into layer.bias_E (there is no I-bias in the current implementation).

Configuration

Network configurations can be specified in YAML:

network:
  name: ExcitationInhibitionNetwork
  params:
    input_dim: 784
    n_layers: 3
    n_excitatory: [200, 100, 10]
    n_inhibitory: [50, 25, 0]
    n_branches: [20, 15, 10]
    connectivity: sparse
    sparsity: 0.2
    activation: relu
    use_batch_norm: true
    dropout_rate: 0.1
    epsilon: 1e-6

input_network:
  name: conv2d
  params:
    in_channels: 1
    out_channels: 32
    kernel_size: 5
    stride: 1
    padding: 2
