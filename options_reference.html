Options reference

This page lists every option of the typed configuration sections with its type and its default value. Each section links the guide that explains its options; start from Configuration guide. Unknown keys raise when a configuration loads (How configs are checked). Some effective defaults depend on other options, for example on the core type; the guides describe those cases.

The payload blocks model.core.population_network and model.core.unified_ei are checked by their model builders and documented with their families (Options reference, Unified E/I core). Sections that plugins provide are described in Configuration sections.
