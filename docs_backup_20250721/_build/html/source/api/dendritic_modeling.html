dendritic_modeling package#

Configuration module for dendritic modeling.

This module contains configuration dataclasses and utilities.

Models module.

This module contains various model implementations including classification, regression, and baseline models.

Networks module.

This module contains various neural network components including layers, architectures, activations, and input transforms.

General utilities for dendritic modeling.

This module contains core utility functions for: - Data handling and serialization - Logging configuration - Random seed management - Data reshaping utilities

dendritic_modeling.utils.roc_auc_score(y_true: Tensor, y_score: Tensor, dim: int | None = None, multi_class: str = 'auto', average: str = 'macro') → Tensor[source]#

PyTorch-native ROC AUC score computation.

Supports both binary and multiclass classification, works on GPU/CPU, and handles multiple batch dimensions with optional reduction.

Parameters:

  • y_true – Ground truth labels. Shape: (…, n_samples)

  • y_score – Prediction scores. For binary: (…, n_samples) or (…, n_samples, 2) For multiclass: (…, n_samples, n_classes)

  • dim – Dimension to compute AUC over. If None, uses last dimension

  • multi_class – ‘auto’, ‘ovr’ (one-vs-rest), or ‘raise’

  • average – For multiclass - ‘macro’, ‘weighted’, or None

Returns:

ROC AUC scores. Shape depends on input shapes and dim parameter.
