Dendritic Modeling Configuration Guide#

This comprehensive guide covers all configuration options available in the Dendritic Modeling Framework. All configurations are specified using YAML files that are passed to the training script.

Overview#

Configuration files define all aspects of dendritic modeling experiments:

```yaml Basic structure ================================================== model:          # Network architecture and parameters train:          # Training strategy and hyperparameters task:           # Dataset and task configuration analysis:       # Analysis and metrics configuration visualization:  # Plotting and visualization options outputs:        # Output directories and saving options wandb:          # Weights & Biases logging configuration ```

Model Configuration#

Network Types#

The framework supports multiple network architectures:

`````yaml model:

task: classification # or “regression”

# Three-part model structure encoder_network:

type: Identity # Input encoder (Identity, CNN, MLP, AlexNet) parameters:

input_dim: 784

core_network:

type: EINet # Main network (EINet, MLP, MatchedParamMLP) parameters:

# See detailed parameters below

decoder_network:

type: Identity # Output decoder (Identity, MLP) parameters:

output_dim: 10

EINet Parameters#

EINet (Excitation-Inhibition Network) is the main dendritic architecture:

Architecture Parameters#

`````yaml model:

core_network:

type: EINet parameters:

# Layer sizes excitatory_layer_sizes: [128, 64, 32] # Excitatory neurons per layer inhibitory_layer_sizes: [64, 32, 16] # Inhibitory neurons per layer

# Branching structure excitatory_branch_factors: [2, 2] # Branching factors for E neurons inhibitory_branch_factors: [] # Usually empty for I neurons

# Connectivity patterns ee_synapses_per_branch_per_layer: [100, 50] # E→E connections ei_synapses_per_branch_per_layer: [50, 25] # E→I connections ie_synapses_per_branch_per_layer: [25, 10] # I→E connections ii_synapses_per_branch_per_layer: [0, 0] # I→I connections (usually 0)

# Synaptic properties somatic_synapses: true # Allow direct soma connections use_shunting: true # Shunting vs subtractive inhibition

Synaptic Selection Mechanisms#

`````yaml

# TopK synapse selection topk_type: standard # “standard”, “stochastic”, “variance”, “deepst” topk_init_method: xavier_normal # Weight initialization method topk_noise_level: 0.0 # Noise for exploration (0.0-1.0)

# Stochastic TopK parameters topk_temperature: 0.5 # Temperature for stochastic selection topk_ultrafast: true # Enable fast approximation

# Dynamic Sparse Training (DeepST) parameters excitatory_target_density: 0.1 # Target connection density inhibitory_target_density: 0.1 rewiring_mode: global # “global”, “local”, “constant_branch” rewire_frequency: 1 # Rewiring frequency (epochs) use_noise: true # Add Gaussian noise sigma: 0.05 # Noise standard deviation freeze_excitatory_connectivity: false freeze_inhibitory_connectivity: false weight_threshold: 1e-6 # Pruning threshold

Activation Functions#

`````yaml

# Reactivation functions reactivate: true # Enable reactivation after branches reactivation_type: param_tanh # Activation function type reactivation_init_m: 1.5 # Initial slope parameter reactivation_init_b: 0.5 # Initial bias parameter

Available reactivation types: * none: No reactivation (identity) * param_tanh: Parametric tanh with learnable m and b * param_tanh_only_m: Parametric tanh with only m learnable * relu: Standard ReLU * sigmoid: Standard sigmoid * tanh: Standard tanh * param_linear_sigmoid: Interpolates between linear and sigmoid * linear_sigmoid: Non-trainable linear-sigmoid interpolation * param_linear_tanh: Trainable linear-tanh interpolation * linear_tanh: Non-trainable linear-tanh interpolation * param_linear_tanh_transition: Smooth transition from linear to tanh * linear_tanh_transition: Non-trainable version

Gradient Scaling#

`````yaml

# Gradient scaling strategies reactivation_strategy: inverse # “none”, “inverse” topk_strategy: conductance_dynamic # “none”, “conductance_dynamic” blocklinear_strategy: conductance_dynamic # “none”, “distal_upweight_by_idx”, “conductance_dynamic”

# Debugging print_hooks: false # Print gradient statistics

Input Processing#

`````yaml

# Input modes input_mode: 1 # 0: raw→E, None→I; 1: same→E,I; 2: network transform

# Input network (for input_mode=2) input_net_dict:

type: CNNInputTransform # Transform network type

# CNN parameters input_shape: [3, 32, 32] # Input dimensions [C, H, W] excitatory_hidden_dims: [16, 32] # E pathway conv channels inhibitory_hidden_dims: [8, 16] # I pathway conv channels excitatory_kernel_sizes: [5, 3] # E pathway kernel sizes inhibitory_kernel_sizes: [7, 5] # I pathway kernel sizes excitatory_strides: [1, 1] # E pathway strides inhibitory_strides: [1, 1] # I pathway strides

# MLP parameters (for MLPInputTransform) hidden_dims: [512, 256] # Hidden layer sizes excitatory_dim: 256 # E pathway output dimension inhibitory_dim: 64 # I pathway output dimension

Available input transform types: * IndexInputTransform: Random index splitting * MLPInputTransform: MLP-based transformation * CNNInputTransform: CNN-based transformation * AlexNetTransform: Pre-trained AlexNet features * FeatureExtractorMLP: Feature extraction MLP * SigmoidInputNetTransform: MLP with sigmoid output

Other Network Types#

Standard MLP#

`````yaml model:

core_network:

type: MLP parameters:

input_dim: 784 hidden_dims: [512, 256, 128] activation: relu # “relu”, “sigmoid”, “tanh” output_dim: 10

Parameter-Matched MLP#

`````yaml model:

core_network:

type: MatchedParamMLP parameters:

# Uses same parameters as EINet to match parameter count input_dim: 784 excitatory_layer_sizes: [128, 64] inhibitory_layer_sizes: [64, 32] # … other EINet parameters

Training Configuration#

Learning Strategies#

`````yaml train:

learning_strategy: standard # Training strategy

# Basic parameters run_name: my_experiment # Experiment name seed: 42 # Random seed train_valid_split: 0.8 # Train/validation split ratio weight_decay_rate: 0.1 # L2 regularization

Available learning strategies: * standard: Traditional backpropagation * freeze_layers: Train layers sequentially * freeze_branches: Train branches sequentially (local learning) * two_step: Local pretraining + global fine-tuning * two_step_kl: Two-step with KL divergence * voltage_stabilization: Biologically-motivated warm-up

Optimizer Configuration#

`````yaml train:

optim_dict:

# Simple configuration split_params: false # Use single learning rate lr: 0.001 # Learning rate

# Advanced configuration split_params: true # Use different LRs for components input_net_lr: 0.001 # Input network learning rate topk_lr: 0.005 # Synaptic weight learning rate blocklinear_lr: 0.001 # Branch aggregation learning rate reactivation_lr: 0.01 # Activation parameter learning rate output_layer_lr: 0.001 # Output layer learning rate

Trainer Parameters#

`````yaml train:

trainer:

# Basic training epochs: 100 # Number of training epochs batch_size: 128 # Batch size loss_function: categorical_nll # Loss function shuffle: true # Shuffle training data

# Optimization grad_clip_value: 5.0 # Gradient clipping

# Early stopping early_stopping: true # Enable early stopping patience: 10 # Early stopping patience load_best_state_dict: true # Load best model after training

# Logging plot_losses: true # Plot training curves suppress_prints: false # Suppress console output print_every: 10 # Print frequency (epochs)

# Strategy-specific parameters pretrain_epochs: 20 # Pretraining epochs (two-step, voltage_stabilization) target_voltage: 0.5 # Target voltage (voltage_stabilization) kl_weight: 0.1 # KL divergence weight (two_step_kl) reverse_training: false # Train in reverse order (freeze strategies) epochs_per_layer: 10 # Epochs per layer (freeze_layers) epochs_per_branch: 10 # Epochs per branch (freeze_branches) final_tune_epochs: 20 # Final tuning epochs (multi-stage strategies)

Available loss functions: * categorical_nll: Categorical negative log-likelihood * mse: Mean squared error * cross_entropy: Cross-entropy loss * bce: Binary cross-entropy

Encoder Network Training#

For models with sophisticated encoder networks:

`````yaml train:

encoder:

# Training mode training_mode: sequential # “joint”, “sequential” train_encoder: true # Whether to train encoder encoder_epochs: 20 # Encoder pretraining epochs

# Independent head training train_heads_independently: false inhibitory_head_objective: classification # “classification”, “diversity”, “combined” diversity_weight: 0.5 # Weight for diversity loss

# Pre-trained weights pretrained_options:

source: none # “file”, “pytorch”, “none” weights_path: “” # Path to weights file pytorch_model: “” # PyTorch model name (e.g., “alexnet”)

Main Network Training#

For multi-stage training strategies:

`````yaml train:

main:

# Parameter groups for different learning rates param_groups:

topk: 0.005 # Synaptic weights blocklinear: 0.001 # Branch aggregation reactivation: 0.01 # Activation parameters output_layer: 0.001 # Output layer

weight_decay_rate: 0.1 # Weight decay

trainer:

# Same parameters as above epochs: 80 batch_size: 128 # …

Task/Dataset Configuration#

Dataset Selection#

`````yaml task:

dataset: mnist # Dataset name data_path: “” # Custom data path (empty = default)

parameters:

# Common parameters train_size: 8000 # Training samples valid_size: 1000 # Validation samples test_size: 1000 # Test samples flatten: true # Flatten images normalize: false # Normalize inputs

Analysis Configuration#

Performance Analysis#

`````yaml analysis:

performance_analysis:

enabled: true # Enable performance metrics training: false # Run during training params:

accuracy: true # Classification accuracy categorical_loglikelihood: true # Log-likelihood mse: false # Mean squared error (regression)

Information-Theoretic Analysis#

`````yaml analysis:

information_analysis:

enabled: true training: false # Usually false (expensive) params:

# Estimation method method: kraskov # “kraskov”, “sklearn”, “copula”, “auto” max_samples: 5000 # Limit samples for efficiency

# k-NN estimator (kraskov) n_neighbors: 10 # Number of neighbors (5-20)

# Histogram estimator (sklearn) n_bins: 20 # Histogram bins

# Copula estimator copula_type: gaussian # “gaussian”, “t”, “clayton”

# Analysis types compute_basic_mi: true # I(E;C), I(I;C), I(Vout;C) compute_pairwise_mi: true # I(E;I), I(E;Vout), I(I;Vout) compute_conditional_mi: true # I(E;I|C), I(E;Vout|C) compute_pid: false # Partial Information Decomposition

# PID settings pid_binarize: true pid_binarize_method: median # “median”, “mean”, “quantile” pid_binarize_threshold: 0.5

# Additional options include_vinf: true # Include soma activation normalize_mi: false # Normalize MI by entropy verbose: false # Detailed progress compute_per_branch: true # Per-branch analysis branch_aggregation: none # Branch aggregation method

Ablation Analysis#

`````yaml analysis:

ablation_analysis:

enabled: true training: false params:

layer_ablation: true # Test removing layers compartment_ablation: true # Test removing E/I compartments ablate_all_synapses: true # Test removing all synapses ablate_excitation: true # Test removing excitation ablate_inhibition: true # Test removing inhibition ablate_upstream: true # Test removing branches accuracy: true # Measure accuracy categorical_loglikelihood: true # Measure log-likelihood

Specialized Analyses#

`````yaml analysis:

# Synaptic turnover tracking synapse_turnover_analysis:

enabled: false training: false # Track during training

# Noise robustness noise_perturbation_analysis:

enabled: false training: false params:

uniform_noise: true # Test uniform noise uniform_magnitudes: [0.1, 0.2] gaussian_noise: true # Test Gaussian noise gaussian_sdevs: [0.1, 0.2] n_samples: 10 # Samples per noise level accuracy: true categorical_loglikelihood: true

# Weight analysis weight_analysis:

enabled: false training: false params:

synapse_weights: true # Analyze synapse weights branch_weights: true # Analyze branch weights

# Synaptic activation analysis synaptic_activation_analysis:

enabled: false training: false params:

network_summary: true # Network-wide stats layer_summary: true # Per-layer stats branch_summary: true # Per-branch stats raw_summary: true # Raw values logspace: false # Log-transformed values downsample: true # Downsample for efficiency samples: 1000 # Sample size

# Branch activation analysis branch_activation_analysis:

enabled: false training: false params:

synapse_activations: true # E/I synapse activations branch_activations: true # Branch outputs network_summary: true layer_summary: true branch_summary: true raw_summary: true logspace: false downsample: true samples: 1000

# Single layer contribution single_layer_contribution:

enabled: true training: false params:

save_plots: true # Generate plots save_csv: true # Save numerical results

Visualization Configuration#

`````yaml visualization:

enabled: true # Enable visualization visualize_epochs: [10, 30, 50] # Epochs for visualization

# Available plot types plots:

  • weights # Synaptic weight matrices

  • activations # Activation distributions

  • gradients # Gradient flow

  • profiles # Dendritic profiles

  • branch_info # Branch information content

  • branch_ablation # Branch ablation effects

  • layer_ablation # Layer ablation effects

  • dendritic_ablation_all # Comprehensive ablation

  • dendritic_information # Information processing

  • dendritic_information_inputs # Input information

  • dendritic_information_activations # Activation information

Output Configuration#

`````yaml outputs:

dir: ./outputs/ # Base output directory run_name: experiment_001 # Run identifier

# Subdirectories created automatically: # - models/: Model checkpoints # - logs/: Training logs # - analysis/: Analysis results # - visualizations/: Generated plots

Weights & Biases Configuration#

`````yaml wandb:

use_wandb: true # Enable W&B logging entity: my_username # W&B username/team project: dendritic_modeling # Project name group: experiments # Run group tags: [dendritic, ei_network] # Run tags

FSDP Configuration#

For large models, enable FSDP in train section: `````yaml train:

use_fsdp: true fsdp_config:

mixed_precision: true cpu_offload: false sharding_strategy: full

Run with torchrun for multi-GPU.

topk: 0.005 blocklinear: 0.001 reactivation: 0.01 output_layer: 0.001

dataset: cifar10 parameters:

  • weights

use_wandb: true project: advanced_dendritic tags: [cifar10, two_step, stochastic]
