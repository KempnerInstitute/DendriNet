Runnable Config Examples

These YAML files are copy-paste starting points for local runs. The first four are the primary vision examples; the recurrent examples exercise the newer population, synapse-type, structured-connectivity, and spiking components.

Recommended Example Ladder

The examples are organized so a user can move from the original E/I model to the fully compositional population-network notation without changing more than one idea at a time.

Step

Config

What it teaches

  1. Original feedforward E/I

configs/examples/standard_mnist.yaml

Legacy-compatible shunting MNIST with the current recommended occupancy_quantile gate initialization.

  1. Same model, canonical notation

configs/examples/standard_mnist_population_network.yaml

The same E/I computation written as named populations and explicit directed connections.

  1. Multiple populations in one feedforward layer

configs/examples/population_network_heterogeneous_feedforward.yaml

PV/SST-like inhibitory populations and multiple excitatory morphologies in one layer.

  1. Explicit multilayer routing

configs/examples/population_network_two_layer.yaml

Cross-layer sources such as layer0.e0 and local same-step inhibition in each layer.

  1. Recurrent microcircuit

configs/examples/population_network_recurrent_pyr_pv_sst.yaml

Delayed recurrent edges, connection probabilities, and recurrent training.

  1. Biophysics extensions

population_network_synapse_types_ampa_nmda_gaba.yaml, population_network_spiking.yaml, population_network_soma_feedback.yaml

Typed conductance traces, LIF soma output, and previous-timestep soma-to-dendrite feedback.

  1. Developmental sparsity

configs/examples/standard_cifar10_dense_to_sparse_population_network.yaml

Dense-to-sparse TopK warmup and pruning in the population schema.

All scripts under src/dendritic_modeling/scripts are package-owned entry points and should be tracked. Local scratch scripts in the repository root scripts/ directory are intentionally ignored.

MNIST Single Layer

Original single-layer MNIST feedforward example:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/standard_mnist.yaml

Population Network Feedforward

The same feedforward E/I computation can be expressed with named populations: input -> i, input -> e, and same-step i -> e inhibition. This is the smallest example of the canonical layer schema; adding PV/SST/VIP or distinct morphologies is done by adding population blocks and directional edges.

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_feedforward.yaml

Population Network Heterogeneous Cell Types

Multiple E and I populations can live in the same feedforward layer. The example below combines PV-like and SST-like inhibitory populations with deep and flat excitatory populations, each with its own morphology and PopulationConfig overrides:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_heterogeneous_feedforward.yaml

Population Network Recurrent

The same schema becomes recurrent by adding timing: delayed connections on a recurrent layer. Same-step input edges drive the current timestep; delayed population edges read previous-timestep outputs.

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_recurrent_pyr_pv_sst.yaml

Population Network with Independent Transfer

To reproduce the legacy independent-pathway TransferLayer split, use input_e and input_i as explicit first-layer sources:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_independent_transfer.yaml

Population Network Two-Layer E/I

The old two-layer E/I shape, 128E/32I -> 64E/16I, can be written as two population-network layers. Layer 0 uses input -> i0 and input -> e0. Layer 1 then addresses the earlier populations explicitly, for example layer0.e0 -> i1, layer0.e0 -> e1, and layer0.i0 -> e1, before local same-step i1 -> e1 inhibition:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_two_layer.yaml

AlexNet 500E Replacement

AlexNet fc7 replacement with a 500E-only dendritic tensor-map core. For real training, set data.base_dir or IMAGENET_LOCAL_DIR to a local ImageNet root. The example uses pretrained ImageNet preprocessing and disables fake-data fallback; for loader smoke tests without the real dataset, set data.dataset_params.imagenet.allow_fake_data: true explicitly.

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/alexnet_fc7_dendritic_500.yaml

Recurrent Population Networks

Use population_network_recurrent_pyr_pv_sst.yaml for named recurrent E/I cell populations. It uses the same population_network.layers[] and connections notation as feedforward population examples:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_recurrent_pyr_pv_sst.yaml

Taus and Delayed Edges

Temporal constants are explicit. layers[].dt is the update step, tau_base/tau_ratio or level_taus define dendritic trace decays, and timing: delayed connections read the previous timestep. Receptor-style synapse_types add their own tau_rise/tau_decay traces:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_taus_and_delays.yaml

Multilayer Recurrent Population Network

Multiple recurrent population layers can be stacked. Later layers can consume any earlier population by qualified source name, for example layer0.e0 or layer0.pv0. Local same-step edges remain directional, while recurrent feedback uses timing: delayed:

PYTHONPATH=src:$PYTHONPATH python \
  src/dendritic_modeling/scripts/training/train_experiments.py \
  configs/examples/population_network_multilayer_recurrent.yaml

DeepSeek-V3 MLP Replacement Template

Transformer replacement uses the same target-plus-core structure as the AlexNet examples, but is applied to a Hugging Face model object rather than the vision training script. The template below replaces decoder-block MLPs 0, 1, 2 with a token-wise dendritic FFN using indexed_dynamic sparse candidate pools:

configs/examples/deepseek_v3_mlp_dendritic_replacement.yaml

Transformer Replacement Distillation Smoke Test

This example trains a small dendritic transformer-MLP replacement against a synthetic teacher MLP. It is the fastest check that the replacement and the new training.transformer_replacement block are wired correctly before loading a large Hugging Face model:

configs/examples/transformer_replacement_synthetic_distillation.yaml

PYTHONPATH=src:$PYTHONPATH python -m \
  dendritic_modeling.scripts.training.train_transformer_replacement \
  configs/examples/transformer_replacement_synthetic_distillation.yaml

Transformer Replacement Benchmarks

Benchmark configs live under jobs/transformer_replacement_benchmarks/configs/. Each job first trains the dendritic replacement and then benchmarks the original teacher block against the trained replacement on held-out hidden states:

jobs/transformer_replacement_benchmarks/configs/synthetic_linear_projection.yaml
jobs/transformer_replacement_benchmarks/configs/synthetic_gelu_mlp.yaml
jobs/transformer_replacement_benchmarks/configs/synthetic_gated_silu_mlp.yaml

Slurm launch scripts are in jobs/transformer_replacement_benchmarks/. The aggregate output is written to results/transformer_replacement_benchmarks/summary.md and summary.csv.
