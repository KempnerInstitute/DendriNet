Contributing

Development Setup

conda activate dendritic_env
pip install -e ".[dev]"

This installs pytest, ruff, sphinx, and pre-commit hooks.

Code Style

The project uses ruff for linting and formatting. Configuration is in ruff.toml. Run checks with:

ruff check src/ tests/
ruff format src/ tests/

Do not suppress lint warnings with # noqa comments. Fix the underlying issue instead (move imports, restructure code, etc.).

Testing

PYTHONPATH=src:$PYTHONPATH python -m pytest tests/

Test markers: @pytest.mark.unit, @pytest.mark.integration, @pytest.mark.slow, @pytest.mark.requires_gpu, @pytest.mark.requires_data.

Building Documentation

cd docs
make html

View the generated site at docs/_build/html/index.html from the repository root.
