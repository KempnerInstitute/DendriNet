# Installation

In a fresh Python 3.10 or later environment, install the library with
`python -m pip install dendritic-modeling==0.5.0`. To use the graphical
editor, run `python -m pip install --upgrade dendrinet-studio` and
`dendrinet-studio --workspace my-runs`. Studio installs the compatible core.

The installation guide covers virtual environments, PyTorch CPU and CUDA
wheels, editable installs and a first training run.
[Installation guide](docs/installation.rst)
