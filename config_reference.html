Population-Network Reference Config

This page reproduces configs/config_exp.yaml – the authoritative single-GPU reference config for the population_network schema. E/I compatibility fields are supported by the loader and factory for existing configs, but they are not duplicated in this runnable template.

Copy this file as your starting point and modify as needed.
